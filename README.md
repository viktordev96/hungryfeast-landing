# Hungry Feast Landing

Professional, performance-focused landing page for Hungry Feast (buffet & grill).
Optimized for SEO, fast load, and bilingual (EN/ES) toggle.

## Features
- Lightweight static HTML/CSS/JS
- English default + Spanish toggle
- SEO meta + JSON-LD (Restaurant)
- Responsive layout and image slider background

## Local Preview
Open `index.html` directly in the browser.

## Project Structure
- `index.html` - landing layout and content
- `styles.css` - styles and responsive rules
- `main.js` - interactions + EN/ES translations
- `assets/` - logo and slider images

## Deploy to GitHub Pages
1. Push to a GitHub repo (public repo required on free plan).
2. In GitHub: `Settings -> Pages`
3. Source: `Deploy from a branch`
4. Branch: `main` and folder: `/ (root)`
5. Save. GitHub will provide the live URL.

## Notes
Update the canonical URL and social meta once the live domain is known.
